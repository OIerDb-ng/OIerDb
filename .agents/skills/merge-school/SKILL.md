# 合并学校条目

帮用户合并 `data/school.txt` 里被错误拆成多条记录的学校。一律并入行号靠前的条目，把靠后条目独有的别名加过去，再把靠后的条目用 `,,` 标成无效。

## 数据格式

每个非注释、非空的行都是逗号分隔的字段

```
省份,城市,正式名称,别名1,别名2,...
```

- 以 `#` 开头的行是注释。
- 前三个字段必须有，依次是省份、城市、正式名称。
- 之后的字段都是别名，可以没有，也可以很多。
- 只含 `,,` 的行是已作废的条目，解析器会跳过它。

**示例**

```
湖南,长沙市,长沙市雅礼中学,湖南省长沙市雅礼中学,湖南省长沙雅礼中学,长沙雅礼中学,雅礼中学
```

## 合并的原理

两行表示同一所学校时

1. 保留行号靠前的条目，它作为主条目。
2. 从靠后的条目收集独有的别名，包括它的正式名称（如果和主条目不同）以及主条目还没有的别名。
3. 把这些别名追加到主条目行的末尾，用逗号分隔。
4. 把靠后的条目整行替换成 `,,`，标记为无效。

主条目的省份、城市、正式名称永远不改。两个条目城市不同时提醒用户，它们可能是真的两所学校。

## 预备步骤 获取 issue 上下文（如有）

用户给了 GitHub issue 编号（比如 "merge school #123"），先取来看。

```bash
gh issue view <number>
```

从 issue 提取学校名、行号、省份和合并要求，带着全部信息进入第 1 步。

## 工作流程

### 第 1 步 定位学校

从用户输入提取学校名或线索，用带行号的 `grep` 找候选，不要整读文件。

```bash
grep -n '学校名' data/school.txt
```

要精确匹配第 3 个字段的正式名称，用

```bash
awk -F',' '!/^#/ && $3=="正式名称" {print NR": "$0}' data/school.txt
```

在所有字段（正式名称或别名）里搜关键词，用

```bash
grep -n '关键词' data/school.txt
```

### 第 2 步 识别并评估

过一遍所有匹配行，弄清

- 哪些行表示同一所学校（重复或被错误拆分）。
- 哪一条是行号靠前的条目，它就是合并的目标。
- 省份和城市是否一致。城市不同就先向用户指出，再继续。
- 靠后的条目有哪些别名是靠前的条目没有的。

### 第 3 步 提出合并方案

完整展示两个条目，然后给出方案

- **主条目**（保留），行号靠前的那条（第 N 行），展示完整内容。
- **被并条目**（作废），行号靠后的那条（第 M 行），展示完整内容。
- **要新增的别名**，列出被并条目里有而主条目没有的名字。
- **结果**，展示合并后主条目行会变成什么样。

两个条目的省份或城市对不上，或者拿不准是不是同一所学校，先问用户。

用 `AskUserQuestion` 在改动前确认方案。没有用户明确同意不要动手。

### 第 4 步 执行合并

**注意。** `Edit` 工具要求在会话中至少用 `Read` 读过该文件一次才能编辑。school.txt 很大，用 `Read` 的 `offset` 和 `limit` 只读目标行附近（比如 `offset=行号-1, limit=3`），既满足前置条件，又不加载整个文件。

**第 4a 步，更新主条目行。** 把被并条目独有的别名追加到主条目行的末尾

```
<原主条目行>,<新别名1>,<新别名2>,...
```

用 `Edit`，`old_string` 填原来的整行，`new_string` 填追加后的版本。`old_string` 在文件里必须唯一，必要时带上足够的上下文。

**第 4b 步，作废被并条目行。** 把被并条目整行内容替换成 `,,`。用 `Edit`，`old_string` 填原来的整行，`new_string` 填 `,,`。不要删除这一行，`,,` 占位符保住了文件的行结构，也告诉后来的读者这条记录已被并走。

### 第 5 步 提交

全部编辑完成后用 `AskUserQuestion` 问是否提交。默认提交标题按这个格式

```
data: fix {正式名称} ({省份})
```

比如合并湖南的长沙市雅礼中学，标题是

```
data: fix 长沙市雅礼中学 (湖南)
```

预备步骤里拿到过 issue 编号的话，在提交信息正文末尾加一行

```
Resolves {owner}/{repo}#{issue_number}.
```

然后用确认过的标题和信息创建提交。

## 重要规则

- 一律并入行号靠前的条目，主次不能颠倒。
- 不带 grep/awk 过滤不要读 school.txt，文件约 1.3 万行。
- 请求确认前完整展示两个条目。
- 两个条目的省份或城市不同时重点提醒，它们可能是两所不同的学校。
- 只添加主条目还没有的别名，要对照主条目的全部已有别名检查，不只是正式名称。
- 永不改主条目的正式名称、省份、城市。
- 被并条目替换成 `,,`，不要删除。
