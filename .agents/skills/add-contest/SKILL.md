# 添加比赛数据

本仓库的全部数据由 `data/raw.txt`（每行一条记录）、`data/contests.json` 和学校目录 `data/school.txt` 派生。添加一场比赛，就是把一份官方获奖名单导出转成格式正确的行，追加进这些文件。命令本身都简单，容易出事的是两条约束，违反了也不报错。

- **三个文件都只能追加，背后的原因相同。** `data/raw.txt` 的文件头明说了这一点，插入或调换行会打乱下游所有 OIer ID。`generator/contest.py` 和 `generator/school.py` 说明另外两个文件没有区别。`Contest` 和 `School` 在解析时按位置赋 `self.id`（`idx = Contest.count_all()` / `School.count_all()`）。往 `contests.json` 数组中间插一场新比赛，或往 `data/school.txt` 中间插一行，它后面每个条目的 ID 都会悄悄变。所以新 contest 对象一律放在 `contests.json` 数组的最末尾，不要为了时间顺序整齐而插到已有条目中间。新学校一律作为新行加在 `data/school.txt` 的最末尾，不插入、不移动、不删除。
  - 这条约束不禁止的只有一件事，原地修改 `school.txt` 某一行的内容。追加别名、改错字、修正城市都行，也不管这一行在文件里的什么位置。改的是这行上的内容，不是它前面的行数，ID 不会动。下面第 9 步把未知校名作为别名并入已有学校，用的就是这个口子。
- **同一场比赛内部，分数随追加顺序只能相等或下降，不能上升。** `generator/contest.py` 按你追加的顺序把每条新记录和上一条比，分数一上升就打印警告。警告不是错误，拦不住你。所以比赛在 `raw.txt` 里的数据块必须先按分数降序排好再追加。

下面这些步骤都是为了把一批格式对、排序对的行准备好，一次追加，再做校验。

**前置条件。** 运行任何 `python3` 命令前先激活项目虚拟环境，`source generator/.venv/bin/activate`。

## 第 1 步 把 HTML 导出转成 CSV

```bash
python3 generator/tools/excel_html_to_csv.py "<输入文件.html>" "<workfile>.csv"
```

输出放在临时目录（比如 `generator/dist/` 或你的草稿目录），不要直接放进 `data/`。起个之后还能认出来的名字，在数据落到 `raw.txt` 之前你会生成好几个中间文件。

转换完立刻去掉回车符。这个工具用的 CSV 模块写出 `\r\n` 行尾，而仓库里所有文件（`data/raw.txt`、`data/school.txt`）都用 `\n`。两种行尾混在一起，后面 `sed` 的行号范围和 `$` 结尾的正则都会变得不可靠，漏网的 `\r` 字节还会被提交进 `raw.txt`。

```bash
tr -d '\r' < "<workfile>.csv" > "<workfile>.lf.csv"
```

**相信行号之前先检查折行单元格。** Excel 的 `发布为网页` 导出有时会在长单元格（通常是学校名）里放一个 `<br>`，这个工具把它变成真的换行，于是一条逻辑记录占两行，例如

```
CCF-NOIP2025-1378,YN-0009,云南,田昀可,女,136,"红河哈尼族彝族
 自治州第一中学",高一,范春节
```

这个仓库里确实出过这种事。获奖名单表格一般在源文件里就标了各等级的人数（比如金牌区块前有一行写着“金牌54名”），拿它当校验。你要提取的某个等级行数和标注人数对不上，就找找有没有折行单元格把一条记录拆成了两行，先删掉内嵌换行接回去，再继续。

## 第 2 步 按奖项等级切分，只用 `sed`

先读一遍（或 `grep -n`）CSV，确定每个奖项等级的确切行号范围。横幅行和表头行如果存在，会标出每个等级从哪里开始、到哪里结束。用 `sed -n` 把每个等级提取到各自的文件里。不要改用通用脚本或编辑器，这里要的是一段可复查的精确行号切割，能对照源文件标注的人数复核。

```bash
sed -n '4,57p'   "<workfile>.lf.csv" > "<workdir>/gold.csv"
sed -n '60,205p' "<workfile>.lf.csv" > "<workdir>/silver.csv"
sed -n '208,290p' "<workfile>.lf.csv" > "<workdir>/bronze.csv"
```

切出来的每个文件里只能有获奖记录行，不能有表头行、横幅行，也不能有末尾空行。表头行有时会在范围中间重复出现（有些导出分页后重打一遍列名），这时再接一个 `sed` 删掉，例如 `sed -n '...' file | sed '/^证书编号,/d'`。

## 第 3 步 在 `data/contests.json` 里登记比赛

找一场最相似的往届比赛（相同简称前缀，`NOIP`、`CSP提高`、`NOI`、`NOI...夏令营`、`APIO`、`WC` 等）当模板。各字段的含义如下。

- `name`，比赛的唯一标识，会作为 `raw.txt` 第一列的内容，比如 `NOIP2025`、`CSP2025提高`、`NOI2026`、`NOI2026夏令营`。严格照同系列往届条目的命名方式来，年份放在哪、要不要带 提高/入门/夏令营 后缀，都看旧条目。
- `type`，计分类别。它不一定等于当年的 `name`，比如 `CSP2025提高` 的 type 是 `CSP提高`，任何 `*夏令营` 比赛的 type 是 `NOID类`。每个 `type` 值必须已在 `data/scoring.json` 里存在，那里定义该类型的计分系数。如果这场比赛真是新系列，`scoring.json` 里找不到对应的 type，就明确告诉用户。只在 contests.json 里登记是不够的，`scoring.json` 也得加条目，这超出本技能的范围。
- `year`，比赛年份（整数）。
- `full_score`，满分。要和第 4 步实际提取的分数列核对，不能只抄去年的值，满分是会变的。
- `fall_semester`，是否秋季学期办赛。CSP、NOIP 这类秋天办的填 `true`，NOI、IOI、APIO、WC、CTSC 这类夏天办的填 `false`。参考同系列往届条目。
- `capacity`（可选），部分比赛类型有这个字段（IOI 的队伍规模、CSP/NOIP 的报名总数），另一些从来没有（WC、APIO、CTSC、NOI 本身都不带）。同系列往届条目有才加，而且只在确实知道数值时填，不要猜。

写入前用 `AskUserQuestion` 把要添加的完整对象展示给用户，让用户确认或修改。这些字段事后很难改，`raw.txt` 第一列必须和 `name` 一字不差。新对象加在数组最末尾，不要为了时间顺序好看而插到前面。原因见开头关于只能追加的说明，条目的位置就是它的 ID，往中间插一条，后面的条目全部会被重新编号。

## 第 4 步 把切分后的 CSV 规范成目标格式

目标格式是 9 个逗号分隔的列。`标识符` 留空，但末尾的逗号必须保留，列数才正好是 9。`generator/main.py` 要求每行恰好 9 个字段，差一个整行都会被拒绝。

```
比赛名称,奖项,姓名,年级,学校,分数,省份,性别,标识符
```

示例

```
CSP2022提高,一等奖,任宝硕,高二,石家庄二中实验学校,215,河北,男,
```

写正则之前要先知道源文件的列顺序，也就是第 2 步切分前的那个表头。第 2 步把表头行丢掉了，所以要提前把顺序记下来。源导出很少正好是目标顺序和列数。一份真实 NOI 导出的列是 `证书编号,姓名,省份,性别,学校(全称),年级,实际总分,加5分,总分,集训队,指导教师`，共 11 列，其中有两列看起来都像分数。一定要确认哪一列是最终官方分数，能和第 3 步填的 `full_score` 对上，别拿加分前的小计。

用 `([^,]*),` 捕获一个普通单元格。这假设该切分文件里没有单元格内嵌逗号。源工具如果因为字段含逗号而加了引号，引号会留在文件里，这样的行手工处理，不要硬套正则。按源文件的列数搭一个捕获组替换，只输出需要的列，按目标顺序排列，奖项等级和比赛名直接按字面写死。整个文件里它们是常量，这正是第 2 步先按等级切分的原因。

```bash
sed -E 's/^([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*),([^,]*)$/NOI2026,金牌,\2,\6,\5,\9,\3,\4,/' \
  "<workdir>/gold.csv" > "<workdir>/gold.normalized.csv"
```

这里 `\2` 是姓名、`\6` 是年级、`\5` 是学校、`\9` 是总分、`\3` 是省份、`\4` 是性别，对应那份源文件的列顺序。换一份导出，就照实际看到的表头重推一遍映射。

规范的同时顺带检查

- **省份** 必须与 `generator/util.py` 里 `provinces` 列表中的某一项完全一致，不带 `省`/`市`/`自治区` 后缀。要写 `河北` 不是 `河北省`，要写 `内蒙古` 不是 `内蒙古自治区`。
- **性别** 最后应是 `男` 或 `女`，不确定或没提供就留空。
- **奖项** 必须是 `generator/util.py` 里 `award_levels` 之一（`金牌`/`银牌`/`铜牌`/`一等奖`/`二等奖`/`三等奖`/`国际金牌`/`国际银牌`/`国际铜牌`/`前5%`/`前15%`/`前25%`）。

## 第 5 步 合并规范后的文件

```bash
cat "<workdir>/gold.normalized.csv" "<workdir>/silver.normalized.csv" "<workdir>/bronze.normalized.csv" \
  > "<workdir>/merged.csv"
```

## 第 6 步 按分数降序排序

这一步满足开头说的 `generator/contest.py` 单调性检查。第 6 个字段是分数。

```bash
sort -t',' -k6,6 -rn -s -o "<workdir>/merged.sorted.csv" "<workdir>/merged.csv"
```

`-s` 保持排序稳定，同分的行不会被白白打乱。`-k6,6` 把排序键限定在第 6 个字段，不写第二个 `,6` 的话 sort 会从第 6 个字段一直比到行尾。

## 第 7 步 追加进 `data/raw.txt`

先核对行数。合并排序后的文件行数应该等于第 1、2 步里各等级的人数之和，也就等于源文件上这场比赛的获奖总人数。

```bash
wc -l "<workdir>/merged.sorted.csv"
```

确认 `data/raw.txt` 目前以换行符结尾，不然追加的第一行会粘在原有最后一行后面。`tail -c1 data/raw.txt | xxd` 应该显示 `0a`。然后追加。

```bash
cat "<workdir>/merged.sorted.csv" >> data/raw.txt
```

用户给了多份比赛文件时，对每份重复第 1 到 7 步。比如正赛加一份夏令营或入门名单是两场独立的比赛，各要一个 `contests.json` 条目，各走一遍流程。学校校验等全部追加完再做一次。

## 第 8 步 找出数据引用了但库里还没有的学校

`main.py` 按自身目录解析相对路径（`../data/...`、`dist/...`），必须进入 `generator/` 目录运行。

```bash
(cd generator && python3 main.py --export-unknown-schools) > /tmp/main-run.log 2>&1
```

这条命令对整个 `raw.txt`（几十万行）做一遍完整的解析、校验和分析，很慢，进度条输出也多。把输出重定向到日志文件，别让它流进上下文，怀疑有问题再去看，比如对日志跑 `grep -i warning` 或 `grep -i error`。真正的产出是 `generator/dist/unknown-schools.txt`，每行一对 `省份,学校名`，是 `raw.txt` 里引用了却没能在 `data/school.txt` 里匹配上的学校。匹配先在本省内按名字精确进行，找不到再全局按名字精确匹配。

## 第 9 步 逐个处理未知学校

对 `generator/dist/unknown-schools.txt` 的每一行做二选一的判断。它要么是 `data/school.txt` 里某所已有学校的另一个名字（并入做别名），要么确实还不在库里（新建）。

派子代理并行调查。让它们读 `data/school.txt` 找候选，按 `merge-school` 技能的匹配思路判断，光看名字定不下来就上网搜索确认身份和所在地，校名经常被缩写、调换语序，或者丢了城市前缀。让子代理只回报建议，不要直接改 `data/school.txt`，多个代理同时改一个文件会互相覆盖。名单长的话每个代理分一批学校，不要一所学校一个代理，把并行数量控制在合理范围。

然后由你自己逐条落实。

- **找到了匹配**，把未知名字作为新别名追加到那一行的末尾，做法同 `merge-school` 技能的第 4a 步，在匹配行末尾加 `,<新别名>`。不需要作废任何东西，这里没有重复条目要并掉，只是记一个名字变体。
- **没有把握的匹配**，在 `data/school.txt` 末尾追加一行新学校 `省份,城市,学校名`，比如 `河北,石家庄市,石家庄市第二中学`。四个直辖市（北京/上海/天津/重庆）的第二个字段填区县，不再填城市名，比如 `上海,虹口区,上海外国语大学附属外国语学校东校`。省份必须与 `generator/util.py` 的 `provinces` 列表完全一致。城市或区县上网查，不要猜也不要编，实在查不到就用 `未分区` 占位。学校名必须逐字照抄 `generator/dist/unknown-schools.txt` 里的写法，全角半角标点都要一致，一个括号或逗号的全半角差异就足以让下一轮校验仍然认不出它。

## 第 10 步 重新校验

```bash
(cd generator && python3 main.py --export-unknown-schools) > /tmp/main-run.log 2>&1
```

再看一遍 `generator/dist/unknown-schools.txt`。空了就完成了。不为空就先看有没有变短。变短说明有进展，接着处理。和上次一样长，多半是第 9 步某次修改没生效，复查拼写和标点。`data/school.txt` 里有多个名字相近的学校时，确认改的是那一行。

## 第 11 步 汇报

向用户汇报最终添加的比赛名称、类型、年份，每场比赛追加了多少条获奖记录，中间文件放在哪里（用户可能要检查），以及多少学校并成了别名、多少学校是新建的。

## 可选 提交改动

用户想把改动提交时，沿用 `merge-school` 技能的约定，提议 `add: {比赛名}` 这样的提交信息，提交前先经用户确认。
