# 拆分学校条目

帮用户拆开 `data/school.txt` 里被错误并成一行的两所学校：把属于另一所学校的名称从原行移出，另立一行新学校，并复活一个 `,,` 占位行或追加一个新行来承载它。

## 数据格式

每个非注释、非空的行都是逗号分隔的字段

```
省份,城市,正式名称,别名1,别名2,...
```

- 以 `#` 开头的行是注释。
- 前三个字段必须有，依次是省份、城市、正式名称。
- 之后的字段都是别名，可以没有，也可以很多。
- 只含 `,,` 的行是已作废的条目，仅用来占位保持学校 ID 对齐，解析器会跳过它。

**示例**

```
湖南,长沙市,长沙市雅礼中学,湖南省长沙市雅礼中学,湖南省长沙雅礼中学,长沙雅礼中学,雅礼中学
```

## 拆分的原理

生成器把一行的正式名称和全部别名都注册成这所学校的名字，`data/raw.txt` 里选手记录的学校字段按名称解析（先在省内找，再到全局找），`Record.distance()` 还用 `school.id` 参与选手的自动合并。所以一行混进另一所学校的名称时危害有两层：

1. 那个名称名下的所有获奖记录都被记到了原学校头上，原学校的页面混进别人的成绩。
2. 错误的学校归属会顺着影响选手的自动合并，把本该分开的同名选手错误并成一人。

拆分的修法与 merge-school 互逆：

1. **原条目行**：移除属于另一所学校的一个或多个名称，省份、城市和其余字段原样保留。
2. **新学校行**：`省份,城市,新正式名称[,属于它的别名...]`。拆出的名称通常直接成为新学校的正式名称。省份和城市默认沿用原条目；但如果两所学校根本不在同一座城市——这正是常见的错误合并成因——就用拆出学校自己的省市。
3. **落位**：新学校行写进一个现有的 `,,` 占位行（复活它），如果没有合适的 `,,` 行就追加到文件末尾。学校 ID 按行序分配，`,,` 是历史上合并学校留下的废弃占位，复活它既复用死行，也保持文件行数稳定。

## 从链接查学校

用户给的链接形如 `https://oier.baoshuo.dev/school/123`，其中的数字是学校 ID，从 0 开始计数，按非注释、非空行的顺序排。查行用

```bash
awk 'BEGIN{n=0} /^[^#]/ && !/^$/ {if(n==TARGET_ID){print NR": "$0; exit} n++}' data/school.txt
```

**先输出找到的学校行**，让用户在改动之前确认。

## 预备步骤 获取 issue 上下文（如有）

用户给了 GitHub issue 编号（比如 "split school #123" 或提到某个 issue），先取来看。

```bash
gh issue view <number>
```

从 issue 提取学校名、链接、省份和拆分要求（哪个名称属于另一所学校、那所学校的正确省市），带着全部信息进入第 1 步。

## 工作流程

### 第 1 步 定位学校

从用户输入提取学校名或线索，用带行号的 `grep` 找候选，不要整读文件。

```bash
grep -n '学校名' data/school.txt
```

要精确匹配第 3 个字段的正式名称，用

```bash
awk -F',' '!/^#/ && $3=="正式名称" {print NR": "$0}' data/school.txt
```

给了链接就按上面的办法解析出行。用户说"这个学校页面混了别的学校的成绩"时，给的就是原条目；说"某某学校没有自己的页面"时，那个名字多半是原条目里被并掉的别名。

### 第 2 步 弄清哪些名称属于另一所学校

列出原条目的全部名称（正式名称加别名），结合用户和 issue 的背景分成两组：留下的、拆出的。用 raw.txt 验证归属，看某个名称名下记录的省份分布和年份跨度

```bash
awk -F',' '!/^#/ && $5=="学校名" {c[$7]++} END{for(p in c) print p": "c[p]}' data/raw.txt
```

```bash
awk -F',' '!/^#/ && $5=="学校名" {print NR": "$0}' data/raw.txt
```

- 一个名称的记录全在原条目省份之外，或年份衔接不上，就是拆出的证据。
- 拆出的名称成为新学校的正式名称；如果还有别名跟着它走（只属于那所学校的叫法），一起列出来。
- 拿不准的名称宁可先留在原条目里，问用户，不要猜。

### 第 3 步 提出拆分方案

完整展示原条目（行号、完整内容），然后给出方案

- **原条目行**（保留），展示拆分后会变成什么样。
- **新学校行**：内容是什么，放进哪个 `,,` 占位行（行号）。省份、城市与原条目不同时明确指出并说明依据。
- **每个拆出名称在 raw.txt 里的记录数**，这些记录会自动改属新学校，不需要动 raw.txt。

两种特别情形要先向用户指出：

- 要拆出的名称恰好是原条目的正式名称（第 3 个字段）时，原条目要从剩下的名称里挑一个新的正式名称（挑最正式、最完整的叫法），这会改变原学校在网站上的显示名，必须确认。
- 两个名称在 raw.txt 里都出现、且从省份分不出归属时，列出记录问用户怎么分。

用 `AskUserQuestion` 在改动前确认方案。没有用户明确同意不要动手。

### 第 4 步 执行拆分

**注意。** `Edit` 工具要求在会话中至少用 `Read` 读过该文件一次才能编辑。school.txt 很大，用 `Read` 的 `offset` 和 `limit` 只读目标行附近（比如 `offset=行号-1, limit=3`），既满足前置条件，又不加载整个文件。

**第 4a 步，修改原条目行。** 用 `Edit` 把拆出的名称从原行移除，`old_string` 填原来的整行，`new_string` 填移除后的版本。删除中间的别名就删 `名称,` 或 `,名称`，删除行尾的别名就删行尾的 `,...`，注意不要留下空字段或行尾逗号。原行的其他字段原样保留。

**第 4b 步，复活 `,,` 占位行。** 把选定的 `,,` 整行替换成新学校行。`,,` 在文件里出现多次，`old_string` 只写 `,,` 不唯一，必须带上相邻的一两行作为上下文（比如"前一行\n,,\n后一行"整段），确保只匹配目标位置。找不到合适 `,,` 行时改为在文件末尾追加新学校行（`old_string` 用原最后一行，`new_string` 是最后一行加新行）。

### 第 5 步 复核

- 每个拆出的名称应恰好只在 school.txt 的一行（新行）里出现：`grep -n '名称' data/school.txt`。如果还出现在原行或其他行，名称映射会串，必须处理干净。
- 新行的省份必须是 `generator/util.py` 省份列表里已有的省级行政区，未知省份会让生成直接失败。
- 拆学校有可能是为了解开被「传染」的选手错误合并。跑 `generator/.venv/bin/python generator/tools/oier_check.py simulate <姓名>`（工具会按当前 school.txt 解析每条记录的学校），确认受影响选手的学校序列和分组符合预期；仍有问题的按 split-oier、merge-oier 的流程继续处理。

### 第 6 步 提交

全部编辑完成后用 `AskUserQuestion` 问是否提交。默认提交标题按这个格式

```
data: fix {学校名} ({省份})
```

学校名按用户关注的对象选：修"页面混了他校成绩"用原条目的正式名称，补"某校没有独立页面"用拆出学校的名称。比如把深圳中学数理高中从深圳科学高中拆出来，标题是 `data: fix 深圳科学高中 (广东)`。

预备步骤里拿到过 issue 编号的话，在提交信息正文末尾加一行

```
Resolves {owner}/{repo}#{issue_number}.
```

然后用确认过的标题和信息创建提交。

## 重要规则

- 一律从原条目里拆出，原条目的省份、城市永远不改；正式名称只有在它本身就是要拆出的名称时才换，且必须经用户确认。
- 不带 grep/awk 过滤不要读 school.txt，文件约 1.4 万行。
- 请求确认前完整展示原条目和拆分结果。
- 只移除确认属于另一所学校的名称，拿不准的留下并问用户。
- 拆出的名称不得残留在原条目或任何其他行里，否则按名称解析时又会被并回去。
- 新学校行优先复活 `,,` 占位行；编辑 `,,` 时 `old_string` 必须带相邻行上下文保证唯一。
- 不要动 raw.txt：拆出名称名下的记录会随名称解析自动改属新学校。只有当某条记录用的名称留在原条目、却明确属于新学校时，才考虑改那条记录的学校字段，并在方案里单列出来让用户确认。
