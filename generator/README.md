# OIerDb NG Data Generator

本目录中的代码迁移自 [OIerDb-ng/OIerDb-data-generator](https://github.com/OIerDb-ng/OIerDb-data-generator) 仓库。

## 使用

请先安装 Python3，然后安装依赖：

```bash
pip install -r requirements.txt
```

生成数据：

```bash
python main.py
```

生成好的数据会存储在 `dist` 目录下。
